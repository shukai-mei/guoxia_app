# Spec Delta

## MODIFIED Requirements

### Requirement: 查看房源详情
界面 SHALL 展示在租房源的完整信息（标题、位置、户型、面积、月租金、描述、联系方式）与媒体内容（周边图可浏览，内屋视频可播放），并提供发起看房预约的入口；已下架房源 SHALL 展示"房源已下架"提示且不提供预约入口；已关联楼栋的房源 SHALL 展示所属楼栋信息（楼栋名称、地址、租户看中属性）与地址参考图，未关联楼栋的房源 SHALL 不展示预约入口并提示暂不支持预约看房。

#### Scenario: 查看在租房源详情
- **WHEN** 租客点击列表中的某个在租房源
- **THEN** 界面展示该房源完整信息、媒体内容与预约入口

#### Scenario: 查看楼栋信息与地址参考图
- **WHEN** 在租房源已关联楼栋
- **THEN** 租客可在详情页查看楼栋名称、地址、租户看中属性（电梯/楼层/梯户比、快递与生活配套、采光噪音体验）与地址参考图

#### Scenario: 房源未关联楼栋
- **WHEN** 在租房源未关联任何楼栋
- **THEN** 界面不展示楼栋信息，不提供预约入口，并提示该房源暂不支持预约看房

#### Scenario: 浏览图片媒体
- **WHEN** 房源详情包含周边图
- **THEN** 租客可在详情页内浏览这些图片

#### Scenario: 播放内屋视频
- **WHEN** 房源详情包含内屋视频
- **THEN** 租客可在详情页内播放该视频

#### Scenario: 访问已下架房源
- **WHEN** 租客通过链接打开一个已下架的房源详情
- **THEN** 界面展示"房源已下架"提示，不展示预约入口

### Requirement: 媒体临时签名 URL 过期刷新
界面 SHALL 使用后端返回的媒体临时签名 URL 加载媒体（房源媒体与楼栋地址参考图）；当媒体因签名 URL 过期加载失败时，界面 SHALL 自动重新请求房源数据获取新的有效地址并重新加载媒体。

#### Scenario: 签名 URL 过期后自动刷新
- **WHEN** 图片或视频因签名地址过期而加载失败
- **THEN** 界面重新请求该房源数据，使用新返回的签名 URL 重新加载媒体

#### Scenario: 地址参考图签名 URL 过期后自动刷新
- **WHEN** 楼栋地址参考图因签名地址过期而加载失败
- **THEN** 界面重新请求该房源数据，使用新返回的签名 URL 重新加载地址参考图
